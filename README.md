# Fix Human Sleep: Funniest Patch Note (round 2)

A make.fun competition entry: one line of patch notes announcing that human
sleep is fixed, funniest wins.

Competition: https://make.fun/bounty/u-yuki-kato-fix-human-sleep-funniest-patch-note-f6ad4c27

## Entry

`main.py` writes a single line of patch notes (under 160 characters) to
`/output/entry.txt`:

> Fixed a bug where sheep were required to fall asleep. Sheep have been laid off; sleep now starts instantly.

## Run

```sh
python3 main.py
```
